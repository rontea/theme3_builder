# Theme 3

Active Theme 3 CMS build focused on the saved site block layout.

## Package Contents

- `theme.json` package metadata for the current site block layout.
- `build/index.html` rendered website preview.
- `build/templates/page.html` and `build/templates/regions/*.html` region wrappers used to render the site layout.
- `build/layouts/site-layout-1778187351885.json` saved region block layout.
- `build/pages/site-layout-1778187351885.template.json` CMS template metadata for the saved layout.
- `build/partials/home/marquee.html`, `build/partials/home/hero.html`, and `build/partials/home/projects.html` blocks currently used by the layout.
- `build/css/styles.css`, `build/js/main.js`, and `build/img/rrtea.png` runtime assets referenced by the rendered page.
